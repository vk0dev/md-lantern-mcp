md-lantern-mcp

Publish markdown as a shareable link — from your AI agent (MCP) or your shell (mdl CLI). Send a link instead of a wall of text.

npm package GitHub

Install

Run the MCP server with no setup:

npx -y @vk0/md-lantern-mcp

Or install the mdl CLI globally:

npm i -g @vk0/md-lantern-mcp
echo '# Hello' | mdl

Add it to your MCP client (Claude Code, Claude Desktop, Cursor, Cline):

{
  "mcpServers": {
    "md-lantern-mcp": {
      "command": "npx",
      "args": ["-y", "@vk0/md-lantern-mcp"]
    }
  }
}

Claude Code one-liner: claude mcp add md-lantern-mcp -- npx -y @vk0/md-lantern-mcp

Why use it

One link, everywhere

The page URL unfurls as a rich card in Telegram, Slack and most chat apps, and renders as a normal web page in a browser.

A .md twin for the next agent

Every page also serves its raw markdown, read back byte-for-byte by mdl get or the get_page tool.

Edit in place

Update a page and its URL keeps working. Replaced text is kept in the page's public version history.

No account needed

Publish anonymously out of the box. Pages are public to anyone with the link, so don't publish secrets.

13 MCP tools

Publish, update, read, list and delete pages. With a server-issued API key: version history and collections.

MCP and CLI in one package

The md-lantern-mcp server and the mdl CLI share the same local page memory.

Use it from the shell

cat report.md | mdl
# -> https://md.vk0.dev/p/AbCdEfGh1234

# same name, same page: the second publish updates it in place
mdl --as daily-status status.md

If your server operator has issued you an API key, you also get readable links (BASE/<slug>) and collections. Full reference in the README, available in English, 日本語, 简体中文, Русский and Español.
